# Zenou Tweaks Privacy

**Last updated: September 24, 2026**

Zenou Tweaks is designed to operate locally on your Windows computer.

## Information Collection

Zenou Tweaks does not intentionally collect, transmit, sell, or share personal information.

The application does not require an account and does not intentionally collect:

* Names
* Email addresses
* IP addresses
* Usage analytics
* Telemetry
* Advertising identifiers
* System information for remote analytics

## Local System Information

Zenou Tweaks may inspect information on your computer that is necessary for its features, including Windows configuration, hardware information, drivers, storage, network adapters, and system settings.

This information is processed locally by the application and is not intentionally transmitted to a remote server.

## Backups and Logs

Backups, settings, and operation logs are stored locally on your computer.

Zenou Tweaks stores its application data under:

`%APPDATA%\ZenouTweaks`

You can remove locally stored application data through the appropriate Windows file-management tools.

## Third-Party Services

Zenou Tweaks does not intentionally use third-party analytics, advertising, or telemetry services.

## Changes

This privacy notice may be updated if the application's data practices change.

If Zenou Tweaks ever introduces features that collect or transmit user information, this document will be updated to describe those practices.

## Contact

For questions about this privacy notice, contact the Zenou project through its official GitHub repository.
